Requires `SHOKO_API_KEY` exported in the shell. Default Shoko API URL is loopback `http://127.0.0.1:8111`.

**No changes are automatic**: committing this PR will not link anything. Dry-run never writes to Shoko. Apply repeats preflight, aborts the full batch if any current file path, AniDB work ID, episode type/number, AniDB episode ID or title changed, and skips already recognized files. A failed link stops further writes. The script never scans `/Anime`, edits torrent content, refreshes metadata, or starts jobs.

The old 15-file manifest continues to use `APPLY_SHOKO_XREFS_15`; the CLI validates the confirmation count against the selected manifest.
